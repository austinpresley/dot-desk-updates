# Dot desk downloads

Signed and Apple-notarized downloads for the Dot desk macOS menu bar app.

[Download the latest release](https://github.com/austinpresley/dot-desk-updates/releases/latest).

Unzip the download, move **Dot desk.app** to **Applications**, and open it. Replace the old app once to enable automatic updates. Supports Apple Silicon and Intel Macs on macOS 13 or later.

The app checks for updates every four hours, downloads them in the background, and installs them when you quit. Right-click its menu bar icon to check manually or change update settings.

This repository contains release downloads, checksums, release notes, and the signed Sparkle update feed. Source code stays private. No task records, sign-in sessions, or private signing keys are included.
